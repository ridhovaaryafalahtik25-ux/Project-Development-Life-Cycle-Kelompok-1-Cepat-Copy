# Dokumen Kebutuhan Website Cepat Copy

Catatan: Harga, alamat, dan nomor kontak merupakan data simulasi untuk keperluan tugas.

## 1. Tujuan Website

Website Cepat Copy dibuat untuk memperkenalkan usaha fotokopi dan percetakan. Pengunjung dapat melihat layanan, harga, cara pemesanan, dan lokasi toko secara online.

## 2. Target Pengunjung

- Mahasiswa: Fotokopi, jilid makalah dan skripsi.
- Pelajar: Fotokopi materi dan cetak tugas.
- Pegawai kantor: Cetak dokumen, scan, dan laminating.
- Panitia acara: Cetak undangan, brosur, dan spanduk.

## 3. Profil Usaha

- Nama: Cepat Copy
- Slogan: Cepat, rapi, harga mahasiswa
- Jam buka: Senin–Sabtu, 07.30–20.00; Minggu, 09.00–15.00.
- WhatsApp: 0812-0000-0000
- Alamat: Jl. Contoh Kampus No. 12

Seluruh informasi di atas merupakan data simulasi.

## 4. Struktur Konten Website

| Bagian | Isi |
|---|---|
| Beranda | Nama usaha, slogan, tombol WhatsApp |
| Layanan | Fotokopi, cetak, jilid, laminating, scan, dan percetakan |
| Harga | Daftar harga setiap layanan |
| Cara Pesan | Empat langkah pemesanan |
| Galeri | Empat gambar ilustrasi layanan |
| Kontak | Alamat, jam buka, WhatsApp, dan denah |

## 5. Kebutuhan Fungsional

| Kode | Kebutuhan |
|---|---|
| KF-01 | Menu navigasi menuju setiap bagian website. |
| KF-02 | Tabel harga yang menampilkan layanan, satuan, dan harga. |
| KF-03 | Tombol WhatsApp untuk menghubungi usaha. |
| KF-04 | Galeri minimal empat gambar dengan teks alternatif. |
| KF-05 | Keterangan data simulasi pada harga, kontak, dan footer. |
| KF-06 | Tautan untuk langsung menuju konten utama. |

## 6. Kebutuhan Nonfungsional

| Kode | Kebutuhan |
|---|---|
| KN-01 | Website nyaman digunakan di HP dengan lebar 360 px. |
| KN-02 | Tampilan rapi di layar 1024 px. |
| KN-03 | Tombol dan tautan dapat digunakan dengan keyboard. |
| KN-04 | Warna teks dan latar memiliki kontras yang cukup. |
| KN-05 | Gambar menggunakan format SVG yang ringan. |
| KN-06 | HTML valid dan menggunakan elemen yang sesuai. |

## 7. Batasan Website

- Website bersifat statis, menggunakan HTML, CSS, dan gambar.
- Tidak menggunakan database.
- Pemesanan dilakukan melalui WhatsApp.
- Seluruh informasi masih berupa data simulasi.

## 8. Gambaran Halaman Website

1. Header: Logo dan menu navigasi.
2. Beranda: Judul, slogan, tombol WhatsApp, dan tombol lihat harga.
3. Layanan: Daftar enam layanan utama.
4. Harga: Tabel harga layanan.
5. Cara Pesan: Empat langkah pemesanan.
6. Galeri: Empat gambar ilustrasi.
7. Kontak: Alamat, jam buka, WhatsApp, dan denah.
8. Footer: Catatan bahwa data masih berupa simulasi.
