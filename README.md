# Website Profil UMKM: Cepat Copy
Tugas Praktik Kelompok **Perancangan, Implementasi, dan Pengujian Website Profil UMKM** (Pengenalan Website dan Desain Web).

Cepat Copy adalah usaha fotokopi dan percetakan dekat kampus. Situs ini satu halaman yang memuat layanan, harga, cara pesan, galeri, dan kontak.

## Cara menjalankan
1. Unduh atau salin seluruh folder proyek, pastikan strukturnya tidak berubah.
2. Buka berkas `index.html` dengan peramban (klik dua kali, atau klik kanan lalu *Open with*).
3. Tidak perlu server atau instalasi tambahan.

## Alur kerja kelompok
1. Membuat cabang (branch) per anggota, misalnya `html`, `css-layout`, `css-komponen`, `konten`, `uji`.
2. Mencatat setiap perubahan dengan pesan commit yang jelas.
3. Menggabungkan ke cabang `main` setelah diperiksa anggota lain.
4. Mencatat setiap rilis di `CHANGELOG.md`.

## Standar yang dipakai
- HTML semantik: `header`, `nav`, `main`, `section`, `address`, `footer`.
- Teks alternatif pada semua gambar bermakna.
- Fokus keyboard terlihat dan tautan "Lewati ke konten utama".
- Desain responsif: diuji pada lebar 360 px dan 1024 px.

## Sumber gambar dan lisensi
